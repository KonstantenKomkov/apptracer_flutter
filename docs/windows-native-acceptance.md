# Windows: самостоятельная нативная проверка

Дата: 2026-10-23. Продолжение №3, без реальных Tracer credentials.

`tool/check_windows_native.py` запускает release-пример из отдельной временной
копии с пробелами/кириллицей. Единственный DSN указывает на локальный приёмник.
Сценарий `native-crash` вызывает нативное исключение runner без отладчика; после
завершения запускается новый процесс `idle`. Проверка требует ровно один
minidump, исключение `0xc0000005`, имя runner и совпадение GUID/age CodeView с
PE-файлом этой сборки. Путь модуля в dump должен содержать уникальную метку прогона.
Сетевой протокол — native multipart `/api/42/minidump/`, отличный от Dart envelopes.

Скрипт завершает только собственное приложение и Crashpad из своей временной
копии; убирает только соответствующее значение регистрации WER. Чужие процессы,
очереди и записи реестра не очищаются. Нативное падение здесь намеренное.

```powershell
python tool/check_windows_native.py --app packages/apptracer_flutter_desktop/example/build/windows/x64/runner/Release --output build/windows-native/report.json
```

Workflow `windows-runtime.yml` запускает проверку на уже собранном Windows
артефакте: после успешного основного CI либо при изменении этой проверки.
Источник — только push в main текущего репозитория. Перед запуском сверяются
исходники пакетов (кроме Markdown), чтобы новый код не проверялся старым binary.
Для первоначального прогона допустим артефакт сборки `39992634203`: native build
успешен, ошибка его старого loopback-приёмника исправлена и повторно проверена.

**Подтверждено:** [Windows runtime 39995855329](https://github.com/KonstantenKomkov/apptracer_flutter/actions/runs/39995855329)
прошёл: crash без отладчика, один native multipart minidump с `0xc0000005`,
совпадающий CodeView runner, уникальный путь прогона и успешный повторный запуск.
За пятиисекундное окно после получения отчёта дубликатов не было.
7 Python-тестов приёмника и PE/minidump также прошли локально и на Windows.
Первый прогон обнаружил только проблему вывода кириллицы в cp1252-консоль;
JSON-файл сохраняется в UTF-8, консоль теперь использует JSON escapes.

Границы: это локальная доставка native dump и подтверждение соответствия сборке.
Она не доказывает приём Tracer, PDB-файлы/строки на сервере, offline recovery,
остановку/очистку или запрет повторной отправки после отзыва сбора. Даже если
отправка произошла уже после перезапуска, это само по себе не доказывает, что
отчёт отправлен новым процессом: Crashpad может загрузить его самостоятельно.
