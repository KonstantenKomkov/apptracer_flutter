## Historical evidence

Files named `*-acceptance`, `*-audit`, dated SDK reports and `status.md` are
**historical evidence only for their named build, date and environment**. They
are preserved unchanged in substance and do not describe the current quick start
or guarantee newer behavior. In particular:

- [status.md](status.md) — chronological ledger, with different versions in one file.
- [android-sdk-1.6.1-acceptance.md](android-sdk-1.6.1-acceptance.md) — Android SDK 1.6.1, release/R8, API 35 emulator.
- [macos-lifecycle-acceptance.md](macos-lifecycle-acceptance.md) — dated macOS lifecycle series.
- [windows-local-acceptance.md](windows-local-acceptance.md) — Windows 11 x64 local scope.
- [linux-preparation.md](linux-preparation.md) — Ubuntu 22.04.5 x64 VM scope.
- [release-1.2.0.md](release-1.2.0.md) — the 1.2.0 release, not the current version table.
